# Shurt Obsidian Vault Template

This Obsidian vault template is a showcase of the structure, taxonomy, configuration, and customizations that I use in my own personal knowledge management (PKM) system. The goal is to provide inspiration for others on how Obsidian can be used to help structure their lives and record important memories.
